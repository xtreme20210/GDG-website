User Commands

Custom role

  • /customrole create [name] [color] [gradient color] [emoji]: Create a custom role with a name, color, gradient color, and emoji if you have a role that has access to this command
  • /customrole edit [name] [color] [gradient color] [emoji]: Edit your custom role
  • /customrole delete: Delete your custom role

Twitch Integration

  • /live: Lists all channels that are set by admins and whether they are live or not
  • /livecheck [username]: enter any twitch username to check if that person is live

Admin Commands

Custom role

  • /roleconfig access add: Allow members with a specified role to create custom roles.
  • /roleconfig access remove: Remove a role's access to custom role commands.
  • /roleconfig access list: List all roles allowed to use custom role commands.
  • /roleconfig protect add: Protect a role's name and colors against impersonation.
  • /roleconfig protect remove: Remove impersonation protection from a role.
  • /roleconfig protect list: List all protected roles.
  • /roleconfig placement set: Set which role custom roles appear directly below.
  • /roleconfig placement show: Show the current custom role placement setting.
  • /roleconfig status: Show the current custom role configuration.

Twitch Integration

  • /liveconfig add: Add a Twitch channel to the monitored list.
  • /liveconfig remove: Remove a Twitch channel from the monitored list.
  • /liveconfig list: List all monitored Twitch channels.
